# Project Management Dashboard Analysis

## Project Overview

This project focuses on project management analytics and dashboard reporting using Microsoft Project, Microsoft Excel, and Power BI. The dashboard consolidates multiple technology-related projects into a centralized reporting environment for monitoring project performance, timelines, resource allocation, and project progress.

The solution demonstrates the integration of project management tools with business intelligence platforms to generate actionable insights and visual reporting.

---

## Objectives

* Analyze project performance across multiple technology projects
* Track project timelines and milestones
* Monitor project progress and completion status
* Visualize project metrics using Power BI dashboards
* Improve decision-making through centralized reporting
* Integrate Microsoft Project data into analytical dashboards

## Data Workflow

1. Project schedules were created in Microsoft Project.
2. Project data was exported into Excel format.
3. Excel datasets were imported into Power BI.
4. Interactive dashboards and visual reports were developed.
5. KPIs and project insights were generated for decision-making.
